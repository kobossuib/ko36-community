# Contributing / Colaborar

Search existing issues first. Add reproductions to the existing ticket when possible.

For bugs, include the KO-36/Companion version (or say you do not know), numbered steps, expected behavior and what happened. Optional screenshot/video links help. One issue per problem.

For ideas, explain the musical task or problem, your proposed change and any current workaround. Maintainers mark accepted ideas ready; discussion alone does not approve implementation.

Anyone may report or reproduce. Maintainers set priority and status. Toni owns product direction. There is no guaranteed response or release date.

Pull requests in this repository cover the community portal and documentation. Run `npm ci`, `npm run types`, `npm run check`, `npm test`. Fork PRs never receive deployment credentials. Firmware contributions need a separately agreed source-code workspace; do not request or upload private projects here.

All posts are public. Be constructive, avoid personal data and keep evidence relevant. Do not upload full diagnostic archives or sensitive security reports.
